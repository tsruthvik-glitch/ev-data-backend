# ⚡ EV Charging Infrastructure ETL Pipeline

An end-to-end **ETL (Extract, Transform, Load) pipeline** designed to process, clean, validate, and store **Electric Vehicle (EV) charging infrastructure data** sourced from the Open Charge Map (OCM) API.

This project demonstrates **real-world data engineering practices**, including schema design, data quality enforcement, modular ETL architecture, and database loading.

---

## 📌 Project Objectives

- Extract raw EV charging data from API / JSON files
- Clean and normalize highly nested JSON structures
- Enforce data quality and validation rules
- Load structured data into a relational database
- Maintain reproducibility, logging, and scalability
